## 1. العمليات القياسية — تعمل في كل الوحدات الـ15

المعمارية مدفوعة بالميتاداتا، لذا **كل وحدة ترث نفس مجموعة العمليات** دون استثناء.
تعلّمها مرة واحدة وطبّقها على العملاء المحتملين والصفقات والفواتير والمنتجات وكل شيء.

### ➕ الإضافة
| الخطوة | التفصيل |
|---|---|
| **الزر** | «+ جديد» أعلى يسار أي شاشة قائمة |
| **النموذج** | يُبنى تلقائياً من تعريف الوحدة — الحقول المطلوبة معلَّمة بنجمة حمراء |
| **الأنواع المدعومة** | نص · نص طويل · رقم · مبلغ · تاريخ · قائمة منسدلة · بريد · هاتف · رابط · خانة اختيار · ربط بسجل آخر · مستخدم |
| **القيم الافتراضية** | تُملأ تلقائياً (مثلاً: حالة العميل المحتمل = «جديد»، المسؤول = المستخدم الحالي) |
| **التحقق** | الحقول المطلوبة تمنع الحفظ، والأرقام تُنظَّف من النصوص |
| **الأتمتة** | قواعد سير العمل تعمل فور الحفظ وتظهر إشعاراً بما نُفِّذ |

> **صلاحيات:** المستخدم بدور «قراءة فقط» لا يرى زر الإضافة، والخادم يرفض الطلب بـ403 حتى لو استُدعي مباشرة.

### ✏️ التعديل
- **من القائمة:** زر ✎ في نهاية كل صف
- **من التفاصيل:** فتح السجل ثم «تعديل»
- **جماعياً:** تحديد عدة صفوف ← تغيير حقل واحد لكل المحدد دفعة واحدة
- **بالسحب والإفلات:** في شاشات كانبان (الصفقات، الفرص، التذاكر) سحب البطاقة يغيّر مرحلتها فوراً
- **حقول محسوبة:** القيمة المرجّحة للفرص تُحدَّث تلقائياً عند تغيير القيمة أو الاحتمالية
- **سجل التغييرات:** كل تعديل يُسجَّل بالقيمة **قبل وبعد** في تبويب «السجل»

> **عزل البيانات:** المندوب يستطيع تعديل سجلاته فقط — محاولة تعديل سجل زميله تُرفض بـ403.

### 🗑️ الحذف
- **حذف ناعم (Soft Delete):** السجل يُخفى ولا يُمحى من قاعدة البيانات، فيبقى قابلاً للاسترجاع والتدقيق
- **تأكيد إجباري** قبل التنفيذ
- **حذف جماعي:** تحديد عدة سجلات ← «حذف المحدد»
- **حمايات:** لا يمكن حذف وكيل له رصيد مالي غير مسوّى

### 📥 الاستيراد من ملف
1. زر «⬆ استيراد» في أي شاشة قائمة
2. اختر ملف CSV — الصف الأول أسماء الأعمدة
3. النظام يطابق الأعمدة بأسماء الحقول ويتجاهل غير المعروف
4. يظهر عدد السجلات المستوردة

**نصيحة:** صدّر الوحدة أولاً إلى CSV لتحصل على قالب بالأعمدة الصحيحة.
الاستيراد يدعم **الحقول المخصصة** التي أضفتها بنفسك.

### 📤 التصدير إلى ملف
- **CSV** من زر «⬇ تصدير» في كل وحدة — يشمل كل الحقول والحقول المخصصة
- الملف يبدأ بعلامة BOM حتى تفتح **إكسل** العربية بشكل صحيح دون تشويه

### 🔍 البحث والفلترة
| الأداة | الوظيفة |
|---|---|
| **البحث السريع** | حقل البحث أعلى القائمة — يبحث في كل الحقول النصية |
| **البحث الشامل** | شريط علوي يبحث عبر **كل الوحدات** دفعة واحدة |
| **الفلاتر المتقدمة** | شروط متعددة: يساوي · لا يساوي · يحتوي · أكبر من · أصغر من |
| **سجلاتي فقط** | خانة اختيار لعرض ما تملكه أنت |
| **الفرز** | الضغط على رأس أي عمود |

## 2. مركز التقارير — 17 تقريراً جاهزاً

**الوصول:** القائمة الجانبية ← «📑 مركز التقارير»

### التقارير المتاحة

**💰 المبيعات**
| التقرير | المحتوى |
|---|---|
| المبيعات حسب المرحلة | توزيع الصفقات وقيمها على مراحل خط المبيعات |
| أداء المندوبين | الإيراد والصفقات لكل مندوب **مقابل هدفه ونسبة إنجازه** |
| تحليل الفوز والخسارة | أسباب الكسب والخسارة بالعدد والقيمة |
| خط المبيعات المتوقع | الصفقات المفتوحة **بقيمتها المرجّحة** حسب شهر الإغلاق |
| فعالية مصادر العملاء | عدد العملاء ونسبة التحويل لكل مصدر |

**🧾 المالية**
| التقرير | المحتوى |
|---|---|
| **أعمار الذمم المدينة** | الفواتير غير المسددة في فترات: جارية · 1-30 · 31-60 · 61-90 · +90 يوم |
| الإيرادات الشهرية | المفوتر والمحصّل والمتبقي شهرياً |
| المدفوعات حسب القناة | الإجمالي والرسوم والصافي لكل قناة من الـ36 |
| ملخص الضرائب | الوعاء الضريبي والضريبة المحصّلة شهرياً |

**👥 العملاء** — ترتيب العملاء بالإيراد · توزيع الشرائح · الأداء حسب المحافظة
**📦 المخزون** — أداء المنتجات · تقييم المخزون بالتكلفة وسعر البيع
**🎫 الدعم** — ملخص التذاكر حسب الحالة والأولوية والمتأخرة
**🤝 الشركاء** — عمولات الوكلاء: المستحق والمصروف والرصيد
**⚙️ النظام** — سجل نشاط المستخدمين *(للمدير فقط)*

### أدوات كل تقرير
- **فلترة بالتاريخ** مع اختصارات: هذا الشهر · الشهر الماضي · هذه السنة · كل الفترات
- **صف الإجمالي** يُحسب تلقائياً لكل عمود رقمي
- **🖨 طباعة** بتنسيق A4 مصمم للورق: رأس بالشعار واسم التقرير والفترة، ورؤوس الجدول **تتكرر في كل صفحة**، وتُخفى القوائم والأزرار
- **⬇ تصدير CSV** بترميز يدعم العربية في إكسل
- **⬇ تصدير Excel** بملف `.xls` حقيقي بأعمدة منسّقة وترويسة ملوّنة

## 3. إعدادات النظام

**الوصول:** القائمة الجانبية ← «⚙️ إعدادات النظام» *(مدير النظام فقط للحفظ)*

| المجموعة | الإعدادات |
|---|---|
| **🏢 عام** | اسم الشركة · الهاتف · العنوان · الرقم الضريبي · رابط النظام |
| **💰 المالية** | العملة · نسبة الضريبة · بادئة الفواتير · مهلة السداد · بداية السنة المالية |
| **✉️ البريد** | الخادم · المنفذ · المستخدم · كلمة المرور · المرسل · TLS |
| **🤖 الذكاء الاصطناعي** | مفتاح API · النموذج |
| **📊 المبيعات** | التوزيع التلقائي · أيام ركود الصفقة · تفعيل الولاء |

**اسم الشركة يظهر تلقائياً** في ترويسة كل تقرير مطبوع وفي رسائل البريد.
كلمات المرور تُعرض كنقاط ولا تُرسل للمتصفح إطلاقاً.

**تنظيف البيانات التجريبية:** يظهر لمدير النظام فقط في أسفل الإعدادات. يحذف سجلات الأعمال التجريبية بعد إدخال عبارة التأكيد `DELETE DEMO DATA`، ويحافظ على المستخدمين والإعدادات وقوالب البريد والتخصيصات والتكاملات والخريطة العالمية. لا يمكن التراجع عن العملية.

## 5. الصلاحيات

| الدور | الصلاحيات |
|---|---|
| **مدير النظام** | كل شيء + الإعدادات + المستخدمون + الحقول المخصصة + سجل النشاط |
| **مدير مبيعات** | كل البيانات + التقارير + إدارة الوكلاء والقوائم — لا يعدّل إعدادات النظام |
| **مندوب** | **سجلاته فقط** — البيانات المشتركة (المنتجات، المنافسون، الأسواق) متاحة للجميع |
| **قراءة فقط** | اطلاع كامل بلا أي تعديل — محمي على مستوى الخادم لا الواجهة فقط |
