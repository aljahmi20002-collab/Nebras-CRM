# NebrasCRM — الهوية البصرية
**نِبراس سي آر إم** · Visual Identity Kit

---

## المعنى

> **النِّبراس**: المصباح الذي يُهتدى به في الظلام.

الاسم اختير لأن وظيفة نظام CRM هي بالضبط هذه: أن يضيء لك بيانات عملائك فتهتدي بها في قراراتك. والشعار يترجم المعنى حرفياً — **شعلة ذهبية داخل مصباح نيلي**.

الرمز يُقرأ بثلاث طرق متعمدة: **شعلة** (النور والحيوية)، **سهم صاعد** (النمو والمبيعات)، و**منارة** (الاهتداء والثقة).

---

## الشعار

| الملف | الاستخدام |
|---|---|
| `logo/nebras-mark.svg` | الرمز الأساسي — التطبيقات والأيقونات |
| `logo/nebras-mark-rays.svg` | الرمز بأشعة — الصور الرمزية والمناسبات |
| `logo/nebras-mark-bare.svg` | الشعلة بلا خلفية — فوق الصور والخلفيات الملونة |
| `logo/nebras-mark-mono-white.svg` | لون واحد أبيض — الطباعة والختم والحفر |
| `logo/nebras-mark-mono-ink.svg` | لون واحد داكن — الطباعة على الأبيض |
| `logo/nebras-lockup-{en\|ar}-{dark\|light}.svg` | الشعار الكامل مع الاسم والوصف |

> **مهم:** كل النصوص في ملفات الشعار **محوَّلة إلى مسارات (outlines)**، فلا تعتمد على وجود الخط في جهاز المستخدم، وتُعرض بشكل صحيح في أي برنامج.

### قواعد الاستخدام

**✅ افعل**
- اترك مساحة فارغة حول الشعار لا تقل عن **نصف عرض الرمز**
- الحد الأدنى للحجم: **24 بكسل** للشاشة، **8 مم** للطباعة
- استخدم نسخة اللون الواحد عند تعذّر الطباعة الملونة
- استخدم `mark-bare` فوق الصور الفوتوغرافية

**❌ لا تفعل**
- لا تغيّر ألوان التدرج أو تستبدلها
- لا تدوّر الشعلة أو تعكسها أفقياً
- لا تشوّه النسب (استخدم تكبيراً متناسباً دائماً)
- لا تضف ظلاً أو حداً أو تأثيرات على الرمز
- لا تضع الرمز على خلفية منخفضة التباين

## الأيقونات

```
favicon/
├── favicon.svg              متجه — يتكيف مع أي حجم
├── favicon.ico              متعدد الدقات (16/32/48/64)
├── icon-{16…1024}.png       11 مقاساً
├── apple-touch-icon.png     180×180 لأجهزة أبل
└── maskable-512.png         بهامش أمان 15% لأندرويد
```

**لماذا نسخة maskable منفصلة؟** أندرويد يقص الأيقونة بأشكال مختلفة (دائرة، مربع مستدير، معيّن). النسخة العادية ستُقص أطراف الشعلة، لذا نسخة maskable تضع الشعلة داخل منطقة آمنة مع خلفية ممتدة.

## ملفات المطوّرين

| الملف | المحتوى |
|---|---|

```html

<div style="background: var(--nebras-gradient)"></div>
```

## إعادة التوليد

الهوية كاملة **مولَّدة برمجياً** من ملف واحد، فأي تعديل يبقى متسقاً عبر كل المخرجات:

```bash
cd brand && python3 build_brand.py
```

يتطلب: `cairosvg`, `Pillow`, `fontTools`, `arabic-reshaper`, `python-bidi`
