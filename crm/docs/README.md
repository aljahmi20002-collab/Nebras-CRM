## 🔄 إعادة التوليد

```bash
cd docs && python3 make_diagrams.py     # المخططات
cd brand && python3 build_brand.py      # الهوية والأيقونات
```

اللقطات تُلتقط آلياً من النظام الحيّ عبر Electron — راجع سجل الأوامر في دليل المطوّر.

> **ملاحظة:** المخططات تُولَّد برمجياً من ملف Python واحد، لذا تحديث المعمارية
> يعني تحديث سطر في الكود لا إعادة رسم يدوي.
